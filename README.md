# Taushik Chandana — Portfolio V2 ✦

A modern, editorial brutalist portfolio website engineered with Next.js, React, Tailwind CSS, Lenis smooth scroll, and Framer Motion microinteractions.

🔗 **Repository:** [https://github.com/tnex0734-ops/portfolio_v2](https://github.com/tnex0734-ops/portfolio_v2)

---

## ✨ Key Features & Interactions

- **Editorial Brutalist Aesthetics**: Ink black (`#141416`), signature red (`#e52424`), and warm sketch paper backgrounds with architectural grid motifs and tactile borders.
- **Floating Pill Navigation Bar**:
  - Mascot sticker badge with playful scalloped starburst accent.
  - One-click navigation: `Work`, `Playground`, `About`, `Resume`.
  - Stoppable audio player: toggles between `"Play a song"` and `"Fitoor"` with animated equalizer soundwaves.
  - Dedicated `"Let's talk ↗"` call-to-action button.
- **Workstation Spill (Tools)**:
  - 3D tilted MacBook terminal running `WORKSTATION SPILL // 10+ CREATIVE ENGINES LOADED`.
  - 8 physical tool badges (`Figma`, `Next.js`, `GPT`, `Claude`, `Lovable`, `Miro`, `Antigravity`, `Canva`) cascading from beneath the laptop keyboard with neo-brutalist drop shadows and interactive lift physics.
- **Interactive 3D ID Cards (UX/UI Projects)**:
  - Realistic lanyard clips and physical ID badges.
  - Smooth spring 3D flip on hover revealing project dossiers, metadata barcodes, and launch buttons.
- **Horizontal Scroll Achievements**:
  - Sticky viewport horizontal carousel powered by Lenis smooth interpolation.
  - Clean awards showcase without cash prizes, featuring competitive hackathon records and awards.
- **Physical Book Stack Timeline (Experience)**:
  - Realistic spine textures with randomized physical book dimensions.
  - Hanging bookmark ribbons on the right that reveal internship details and roles on hover.
- **Postal Dispatch Letter (Contact)**:
  - Sealed airmail envelope with classic chevron borders and wax seal.
  - Auto-open interaction after 6 seconds (or on user click) with letter emergence.
  - Direct contact links for Email, Phone, and LinkedIn.
- **Emil Kowalski Microinteractions**:
  - Resume button with 3D spring flip state indicating completed download.
  - Creative preloader with animated geometric particles.
  - Full mobile viewport optimization with zero horizontal overflow.

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (Turbopack) & React 19
- **Animations**: Framer Motion & Motion Primitives
- **Smooth Scroll**: Lenis (`@darkroomengineering/lenis`)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React & Simple Icons
- **Language**: TypeScript

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm / yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/tnex0734-ops/portfolio_v2.git

# Navigate into the project
cd portfolio_v2

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
# Run type check
npm run check

# Create production build
npm run build

# Start production server
npm run start
```
